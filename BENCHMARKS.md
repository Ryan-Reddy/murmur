# Benchmarks

Generated by `bench.py`. Numbers are machine-specific.

- CPU: AMD Ryzen Threadripper 2950X 16-Core Processor
- Cores: 16 physical / 32 logical
- Python 3.12.1 on Windows 11
- Measured 2026-09-06 20:10 UTC

## Synthesis cost by thread count

`short` is a lead-in chunk (44 chars), `long` a full sentence (137).
RTF is wall time over audio produced, so below 1.0 is faster than real time.

| threads | short RTF | long RTF | CPU-s per audio-s |
|---:|---:|---:|---:|
| 2 | 1.65 | 1.34 | 1.33 |
| 4 | 1.07 | 0.85 | 1.32 |
| 6 | 0.86 | 0.72 | 1.50 |
| 8 | 0.73 | 0.63 | 1.59 |
| 12 | 0.86 | 0.60 | 1.70 |
| 16 | 0.63 | 0.48 | 1.66 |
| 24 | 0.78 | 0.61 | 2.28 |
| 32 | 0.79 | 0.61 | 2.88 |

Fastest: 16 threads. Cheapest per second of audio: 4. The default picks `max(2, min(16, logical // 2))`, which lands on the physical core count.
